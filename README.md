# RotivMedia

An Android launcher built from scratch for a car head unit, with the **RotivSecurity** visual identity.

It was built and tested on a **ROCO K706 / QF005 firmware (Qianfeng)** head unit, also sold as the H-Tech HT-9864CA. That unit runs real Android 10 (API 29), although it claims to be "Android 13". It has a 1280×800 landscape screen and a Unisoc chip. It should work on other Android 10+ head units, but docking the app windows requires freeform window mode to be available.

**Which head units are compatible?** See the [compatibility list](docs/en/compatibility.md): tested unit, other QF005 units (A-Sure, Hizpo, W5/W1, HiWorld…), partly compatible QF001 units, and how to tell if yours is a QF unit.

> Personal project, not affiliated with QF, ROCO or H-Tech. Use at your own risk.
>

## Home screen

```
┌──────────── head unit status bar (RotivMedia brand drawn behind it) ──────────────┐
│ ┌────────────────────┐ ┌─────────────────────────┐ ┌──────────────────┐            │
│ │                    │ │                         │ │ MEU CARRO        │            │
│ │   Google Maps      │ │   YouTube Music         │ │ RPM     Engine   │            │
│ │   (real app,       │ │   (real app,            │ │ Battery Now      │            │
│ │    docked)         │ │    docked)              │ │ Average Trip     │            │
│ │                    │ │                         │ │                  │            │
│ └────────────────────┘ │                         │ │                  │            │
│ [ Apps ] [ Ajustes ]   └─────────────────────────┘ └──────────────────┘            │
└────────────────────────────────────────────────────────────────────────────────────┘
```

- **Maps on the left** and **YouTube Music in the center** are the real apps. They open in freeform windows placed on top of the screen frames, and you can use both with touch as usual.
- **YouTube and RetroArch** open on the right side, taking over the center and the car data panel. Their controls (play/pause and **Fechar**, "Close") sit in the bottom strip, so they never cover the video or the game. Closing RetroArch needs a second tap so you don't lose a game by accident. When they close, YouTube Music returns to the center.
- **Car data** comes live from OBD2. Tapping the panel opens the "Meu carro" ("My car") screen.
- **Bottom strip:** "Apps" (app list) and "Ajustes" ("Settings").
- The head unit's top bar is transparent on this firmware. The home screen draws a strip behind it with the dragon and "ROTIVMEDIA". The strip is generated by [`tools/barra_central.py`](tools/barra_central.py).

## Features

| Part | How it works |
| --- | --- |
| Welcome | Dragon animation and "BEM-VINDO, YOUR NAME" ("Welcome") when the head unit starts. It plays once per boot, or when waking after the screen was off for 5 min or more. Tap to skip. |
| Docked Maps | Google Maps docked in the left frame. It can be turned off in Settings → Map; then a drawn map appears with speed and shortcuts to Radar, Map only and Drive. |
| Docked YouTube Music | YouTube Music docked in the center frame. When turned off, a built-in player appears instead (cover, progress, like, previous/play/next). |
| YouTube and RetroArch | Open docked on the right, from the app list. |
| Video lock | Optional: pauses YouTube above a chosen speed (from GPS or OBD2). It resumes when the car stops. |
| Speed warning | Beeps above a chosen limit (60 to 120 km/h). |
| My car | A car drawn in code (hatch, sedan, SUV, pickup) in 13 preset colors or a free color, or a photo of your car. |
| OBD2 | Classic Bluetooth ELM327 adapter. Shows RPM, speed, engine temperature, battery, load and intake. It connects automatically when the head unit starts. |
| Fuel use | Average and instant km/l, liters, distance, time and trip cost. Supports Brazilian gasoline (E27) or ethanol. Cars without a MAF sensor use manifold pressure and engine displacement. |
| Check engine | Reads trouble codes and explains them in Portuguese. **Read-only**: the app never clears codes or sends commands to the car. |
| Demo mode | Simulated OBD2 data, to see everything working without an adapter. |
| Remote ADB | Turns USB debugging and Tailscale back on at every boot, so the head unit can be updated over the network (see [Security](#security)). |

## OBD2

1. Use a **classic Bluetooth ELM327** (v1.5 or v2.1). Most head units can't see the "BLE / Bluetooth 4.0 / iOS" adapters.
2. Plug it into the OBD2 port (under the dashboard, driver side) and turn on the ignition.
3. In the **head unit's** Bluetooth settings, pair with it (PIN 1234 or 0000).
4. In RotivMedia: Ajustes → Adaptador OBD2 → **Buscar adaptadores pareados** ("Find paired adapters") → tap the adapter.
5. For accurate fuel figures, choose gasoline or ethanol and enter the price per liter and the engine displacement.

## Building the APK

Requirements: JDK 17+ and the Android SDK (platform 35, build-tools 35). Create a `local.properties` with `sdk.dir=` pointing to your SDK.

```bash
./gradlew assembleDebug
```

The APK is written to `app/build/outputs/apk/debug/app-debug.apk`. Ready-made APKs for each version are in [Releases](../../releases).

To install over an existing version, the APK must be signed with the same key. If you build on your own PC, uninstall the release version first.

## Installing on the head unit

**USB drive:** copy the APK, open it in the head unit's file manager and allow "install unknown apps".

**ADB:**
```bash
adb connect HEAD_UNIT_IP:PORT
adb install -r app-debug.apk
```

### First-time setup

0. **QF005 head unit:** first follow the [unlocking guide](docs/en/unlocking-qf005.md).
1. **Home screen:** press Home and choose "RotivMedia" → "Always". On the QF005 the default launcher is stored in the system's `config_service` (see [docs/en/head-unit-qf005.md](docs/en/head-unit-qf005.md)).
2. **Location and notifications:** allow them when the app asks.
3. **Music access:** tap "Liberar música" ("Allow music") in the bottom strip and turn on "RotivMedia · música". Over ADB:
   ```bash
   adb shell cmd notification allow_listener com.rotivsecurity.launcher/com.rotivsecurity.launcher.MediaListener
   ```
4. **Freeform windows** (needed for docked Maps and YouTube Music):
   ```bash
   adb shell settings put global force_resizable_activities 1
   adb shell settings put global enable_freeform_support 1
   ```
   then restart the head unit.
5. **Remote ADB (optional):**
   ```bash
   adb shell pm grant com.rotivsecurity.launcher android.permission.WRITE_SECURE_SETTINGS
   ```
6. **Offline Maps:** in Maps, profile picture → Offline maps → download your region.

## Security

- On the QF005, `adbd` runs as **root** with `ro.adb.secure=0`. Any device on the same network can connect **without a confirmation prompt**. With remote ADB on, only connect the head unit to networks you own (for example, your phone's hotspot). From outside, reach it only through a private VPN such as Tailscale. Never expose the ADB port to the internet.
- OBD2 is read-only. The project never touches the car's MCU or CAN bus.
- The launcher doesn't need a Google account on the head unit.

## Code layout

| File | Contents |
| --- | --- |
| `Activities.kt` | Home screen (`HomeActivity`, drawn behind the head unit's bar), `OverlayActivity` (Settings, Apps and My car on top of the docked windows) and the split-screen panel |
| `MapDock.kt` | Window docking: `WindowDock` (opens freeform in the frame's rectangle, fixes the size with `am task resize`, moves apps out of fullscreen), `MapDock`, `MusicDock`, `YtDock`, `RetroDock` |
| `LocalShell.kt` | ADB protocol client that runs `am` commands on the head unit itself |
| `RemoteAdb.kt` | Turns debugging back on and asks Tailscale to connect at every boot |
| `ui/LauncherScreen.kt` | Home screen: frames, bottom strip, car panel, player, YouTube, app list |
| `ui/Theme.kt` | Colors, font and scaling (the layout is designed for a height of 400 "dp") |
| `ui/Welcome.kt` | Welcome animation and the once-per-boot logic |
| `ui/SettingsScreen.kt` | Settings, permissions and diagnostics |
| `ui/CarScreen.kt`, `ui/CarArt.kt`, `CarPhoto.kt` | My car screen and the car drawing/photo |
| `obd/Obd.kt`, `obd/Dtc.kt` | ELM327: mode 01 PIDs, fuel use, trouble codes (mode 03) and demo mode |
| `Media.kt` | Media sessions (what's playing, controls) |
| `Drive.kt` | GPS speed, video lock and the foreground service |
| `Apps.kt` | App list, launching apps, split screen |
| `Prefs.kt` | Saved settings |
| `tools/barra_central.py` | Generates the brand strip image for the top bar (Pillow) |
